# PacePulse

PacePulse is a PWA workout timer (HIIT + Muscle Training) built with React + TypeScript + Vite.

## Quick start (dev)

```bash
cd c:\softwares\.git_note\PacePulse
npm install
npm run dev
# or to expose on your LAN:
npm run dev:host
```

Open the printed URL in your desktop browser. To test from a phone on the same network, run `npm run dev:host` and open `http://<YOUR_LAN_IP>:5173` on the phone.

## Build

```bash
npm run build
```

## Install as Android PWA

- Build and host the site on HTTPS (or use a tunneling tool during development).
- Open the site in Chrome on Android and use "Add to Home screen" / "Install".

## Offline behavior

- The site includes a service worker that caches the app shell and assets.
- Uploaded audio files are now persisted in the browser using IndexedDB, so they stay available after reload and while offline.

## App icon and splash screen

- The app now includes custom PWA icon assets in `public/icons`.
- The Android native wrapper includes updated launcher icon assets under `android/app/src/main/res` and a matching adaptive icon background color.

## Create an Android APK (Capacitor)

Prerequisites: Android Studio + Java JDK + Android SDK installed.

```bash
npm run build
npm run cap:copy
npm run cap:open
```

If you have not yet added Android, run:

```bash
npx cap add android
```

Then use Android Studio to build an APK or run on a connected device.

## Notes

- For offline support the app uses a service worker generated by `vite-plugin-pwa`.
- If you want a custom domain like `www.pacepulse.com` you must purchase it from a registrar (domain purchase is separate from hosting). After buying, you still need to host the site on a server or a hosting provider (e.g., Vercel, Netlify, Firebase Hosting).

## Troubleshooting

- If audio doesn't play automatically on mobile, press `Start` once to unlock audio (browser autoplay policies).
- To test on your Android device over LAN, ensure your laptop's firewall allows port `5173` and both devices are on the same network.
